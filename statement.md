# Smart Expense & Budget Manager

## 1. Problem Statement

Managing personal income and expenses manually can be difficult and time-consuming. Users may lose track of their spending, have difficulty monitoring category-wise expenses, and may exceed their planned budgets.

The Smart Expense & Budget Manager provides a simple command-line solution to record income and expenses, manage budgets, and generate basic financial information. It helps users keep their financial records organized and understand their spending patterns.

## 2. Scope of the Project

The project focuses on basic personal finance management through a Java command-line application.

The scope includes:

- Recording income and expense transactions
- Managing expense categories
- Creating and monitoring budgets
- Viewing financial summaries
- Generating category-wise expense reports
- Searching and deleting transactions
- Storing transaction and budget information in text files

The project is designed for basic personal financial management and does not include online banking, real-time bank transactions, or payment processing.

## 3. Target Users

The application is mainly intended for:

- Students who want to track their daily expenses
- Individuals managing personal income and expenses
- Users who want to monitor category-wise spending
- Users who want to set and track simple budgets
- Beginners interested in basic personal finance management

## 4. High-Level Features

- Add income and expense transactions
- View and delete transactions
- Create category-based budgets
- Track budget spending
- Calculate total income, expenses, and balance
- Generate category-wise expense reports
- Find the highest expense
- Search transactions by category
- Validate user input
- Store data using text files
